# D1 评估标准

分别评估人工参考、系统结果、两者对照。原文优先；参考并非天然正确，结构检查也不等于语义支持。材料结构和类型门槛见[案例规范](D1-案例规范.md)。

## 结论

| 结论 | 条件 |
|---|---|
| 通过 | 所有适用G项通过、无X阻断项，所需确认及复核完成 |
| 有条件通过 | 无阻断项但有非阻断问题，列条件、影响和关闭要求；不算最终通过 |
| 不通过 | 任一X项成立或关键标准失败 |
| 无法评估 | 无真实结果／必要材料／实际复核，或对象不可比；不等于通过 |

## G1–G12 检查

| ID | 检查内容 |
|---|---|
| G1 身份／版本 | 产品、官网、套餐、地区、账号与证据范围相符 |
| G2 事实 | 各原子问题在事实基准日与已读材料一致，单位和条件准确 |
| G3 引用有效 | 关键结论有可定位READ；ID、原句、定位、hash匹配 |
| G4 原句支持 | 主语、极性、模态、条件、版本和时间实际支持结论 |
| G5 冲突／缺口 | 双方保留，缺口类型与searchScope真实，不以失败代“没有” |
| G6 推断范围 | 不把个别、官方、有限检索或旧版本扩成普遍事实 |
| G7 独立性 | 核对上游和理由，按具体主张去重，UNKNOWN不计独立支持 |
| G8 六项完整 | 按案例规范逐项核对，未知／失败如实，无伪造占位 |
| G9 状态诚实 | 真实ID、终态、快照、确认、复核与记录一致 |
| G10 参考隔离 | 系统未读参考及预期证据，独立判读发生在阅读结论之前 |
| G11 可复现 | 第二个人能按来源、定位、获取时间和保存依据复找关键原句 |
| G12 问题／意图 | 覆盖原问题；客观不强推推荐，建议使用真实条件和证据 |

## X1–X12 阻断项

| ID | 阻断错误 |
|---|---|
| X1 | 虚构／不可定位关键引用，包括伪造原句、作者、时间或hash |
| X2 | 证据关联错误，原句不支持结论或对象／条件错配 |
| X3 | 证据不足却断言成立 |
| X4 | 同源转载当成多个独立证实，UNKNOWN凑独立票数 |
| X5 | 官方宣称／benchmark当独立实测 |
| X6 | 读取失败、受限、未获取写成没有讨论 |
| X7 | 产品／版本／套餐／地区错配 |
| X8 | 关键结论过度推断或扩大范围 |
| X9 | 参考、预期主张或证据回灌调查；先看结论却声称盲评 |
| X10 | 未运行、未确认、未复核、夹具或手改数据冒充真实过程 |
| X11 | 违反共同核查要求的隐私、时政、引用或负面措辞边界 |
| X12 | 隐藏冲突，伪造缺口类型／范围或删减关键条件 |

不设加权总分；其他优点不能抵消阻断项。页面后来404并不自动构成X1，需核对历史获取依据并标当前不可达；但不能仅凭hash声称已复现原文。“官方未列出”不直接证明不存在，“未取得独立支持”也不证明全部同源。

## 实际评估流程与记录

冻结材料文件版本、问题hash、获取时间和系统快照版本；先查身份，再逐问题、引用、范围、来源，最后检查全部X项。各对象分别在reference / review写G项结论（通过／部分／不通过／N/A）、具体Q/C/E依据、X项是否成立及处理；列最终结论、条件、实际评估人和时间。

自动评估结果只能辅助检查；没有实际人工确认和独立复核不代填签署。有分歧回到原文，保留双方依据；未知和诚实失败不自动否定材料，但缺失验收前提不能标最终通过。
