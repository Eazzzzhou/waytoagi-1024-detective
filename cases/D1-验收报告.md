### 3.1 规则

| ID | 检查 | 自动化程度 |
|---|---|---|
| R1 | 快照/回答/调查符合共享 Zod 契约 | 确定性 |
| R2 | 引用证据/主张 ID 存在，无悬空 | 确定性 |
| R3 | 引用原句与保存证据逐字符匹配 | 确定性 |
| R4 | READ 证据原句、定位、hash、站点/标题、sourceType/contentKind 不缺失 | 确定性（D1 更严格） |
| R5 | 同一 sourceUrl/upstream/originGroup 不重复标独立；译文不作第二独立来源 | 确定性分组；语义独立性仍需人工 |
| R6 | 客观问题快照不应有未请求的 Advice | 确定性（依据 Advice 表） |
| R7 | FAILED/非 COMPLETED/无快照的任务不能当有效结果 | 确定性 |
| R8 | v1 无父；v>1 父版本/归属连续；评估器只读 | 确定性版本链 |
| R9 | 案例 ID 类型、snapshot.investigationId 与 investigation 关联 | 确定性 |
| R10 | 回答为空或所有回答无引用时告警 | 确定性告警 |

不自动判定：引用是否真正支持主张、来源是否独立、是否过度推断、观点是否代表群体、展示是否清楚。这些留给人工参考与丙复核。
