Geist Latin and Geist Mono Latin are served locally; no browser or build-time Google Fonts request is needed.

The unmodified WOFF2 files come from Next.js 16.4.3's bundled next-devtools fonts, pinned by package-lock.json. Geist is published by Vercel and basement.studio under SIL OFL 1.1. The accompanying OFL.txt is from the official geist@1.7.2 npm distribution.

Upstream: https://github.com/vercel/geist-font · https://vercel.com/font

## 中文标题字体（2026-10-25）

Noto Serif CJK SC，SIL OFL 1.1。官方原文件：
- https://github.com/notofonts/noto-cjk/blob/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Bold.otf
- https://github.com/notofonts/noto-cjk/blob/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Black.otf

许可证原件保留为 `NotoSerifCJK-OFL.txt`。原始 OTF 仅存在忽略的 `.cache/design-review/fonts/` 中，不随网页交付。标题固定文案字符清单为 `title-chars.txt`，700 子集 68,496 字节，900 子集 67,244 字节；均小于 100KB。字体由 `next/font/local` 本地加载，只预载标题两档，`display: swap`，启用 Times New Roman fallback 度量调整。用户输入问题、非子集字及引文使用宋体系统回退；正文采用系统无衬线栈，无网络字体请求。

在项目根目录运行（需 fonttools、brotli）：

```powershell
python -m fontTools.subset .cache/design-review/fonts/NotoSerifCJKsc-Bold.otf --text-file=public/fonts/title-chars.txt --flavor=woff2 --output-file=public/fonts/noto-serif-sc-title-700.woff2 --layout-features='*'
python -m fontTools.subset .cache/design-review/fonts/NotoSerifCJKsc-Black.otf --text-file=public/fonts/title-chars.txt --flavor=woff2 --output-file=public/fonts/noto-serif-sc-title-900.woff2 --layout-features='*'
```

固定标题变更时同步字符清单并重新生成，不能把整包 CJK 字体放进 public。
