# 案卷 · WaytoAGI 1024 侦探赛道

围绕一个 AI 产品，查清事实、真实使用观点、争议和证据缺口，并根据用户问题组织回答。用户只想搜索时给客观结果；提供要求并请求建议时，再做适配判断。元宝搜索承担核心检索，海外社区提供原始观点与补充证据。

## 已有探测脚本

`scripts/probe-sites.mjs` 读取环境变量 `TENCENTCLOUD_WSA_APIKEY`，运行时会真实调用元宝并消耗调用额度。配置服务和密钥后可运行：

```sh
node scripts/probe-sites.mjs
```

输出写入 `research/probe-results.json`，默认不纳入版本控制。它是研究脚本，不代表应用或所有平台已经接通。
