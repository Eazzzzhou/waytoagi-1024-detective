# 前端收藏：快速入口

- 人看 `打开收藏.html`：按素材类别筛选，搜索标签，点预览或官网。
- Agent读 `数据/resources.json`：包含各站点的素材特色、技术栈、获取方式、免费范围、许可与MCP状态。只读当前需要的条目即可，自主选择实现方式。
- 配色按具体项目需求选择；Happy Hues 14仅为普通收藏案例，色值在 `配色参考/tokens.css`。
- 探索互动网页、3D作品或趣味小站时，查 `作品集灵感/README.md` 或数据中的 `inspiration` 分类。
- 用户另收藏了Animata Ripple Button，具体链接在数据文件的examples中。
- MCP怎么调用看 `接入/MCP使用说明.md`；实际安装到目标项目，不在此收藏目录安装业务组件。
- 优先复用已有项目代码；使用前查当前官方API、素材权限和许可。其余实现由项目需要决定。
- 更新站点信息改 `数据/resources.json`，再运行 `python 维护/build_library.py` 刷新首页。
