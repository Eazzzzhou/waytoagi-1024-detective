# Happy Hues · Palette 14

普通收藏案例，用户未指定个人配色偏好。来源：[Happy Hues 14](https://www.happyhues.co/palettes/14)，核对日期2026-10-20。

## 色值与角色

| 角色 | 色值 | 建议用法 |
|---|---|---|
| 主背景 | `#fffffe` | 页面主体，保持内容清晰 |
| 标题 / 深色 | `#272343` | 标题、重要图标、主要文字强调 |
| 正文 | `#2d334a` | 长段文字和说明 |
| 主按钮 / 高亮 | `#ffd803` | 主要行动按钮、少量视觉重点 |
| 主按钮文字 | `#272343` | 与黄色按钮背景搭配 |
| 辅助浅底 | `#e3f6f5` | 分区、卡片外部背景 |
| 辅助强调 | `#bae8e8` | 标签、边缘装饰和次级区块 |

页面有多个演示分区，深底卡片和不同卡片文字色属于局部示例；本库先保存主视觉中稳定的七个角色。

## 本库的理解

气质是明亮、友好、轻松、有重点：近白色承载阅读，深紫建立层级，黄色标记核心动作，浅青提供温和分区。适合工具、知识库与轻量SaaS。以上为设计解读，不是用户明确提出的额外限制。

## 如何交给agent

> 本项目可以参考Happy Hues 14：白底、深紫标题、明黄主按钮、浅青区块。先映射到项目现有token，再调整组件。保留足够留白和清晰层级；黄色不作为白底小字号正文。按当前项目内容检验对比度。

样式入口：[tokens.css](tokens.css)。变量只定义基础角色，不覆盖全局body，也不强制所有项目使用这一套颜色。
