# 指定收藏：Animata Ripple Button

- 来源：[官方组件页](https://animata.design/docs/button/ripple-button)
- 所属站点：Animata；素材类别：基础组件 → 按钮 → 点击反馈。
- 用户提供了此具体链接，作为明确收藏，不推断为所有按钮都必须有涟漪。

## 它解决什么问题

在点击发生的位置扩散涟漪，帮助用户感知按钮已接收到动作。属于短时微交互，适合主次按钮上的局部反馈；它不能代替真正的loading状态、提交成功或错误提示。

## 获取与集成

1. 打开组件页，分别查看预览、组件源码及使用示例。
2. 以当前官方代码为准，将源码放入目标项目组件目录，并对照当前依赖安装需要的包。这里不杜撰组件CLI命名。
3. 统一按钮颜色、大小、字重和圆角；若采用Happy Hues 14，可使用黄色背景、深色文字和不遮挡文字的半透明涟漪。
4. 检查相对定位、overflow裁剪与焦点环的关系，避免裁掉键盘焦点。
5. 若包含事件、ref或浏览器API，按目标工程处理客户端边界。

## 验收

- 原生button标签，type符合表单语义。
- 鼠标点击、触摸、Enter与Space都有明确反馈。
- disabled及提交中的loading状态阻止重复动作。
- 涟漪不会挡住标签，不改变按钮布局，不吞掉事件。
- 快速连续点击没有残留节点或动画堆积。
- reduced-motion时弱化或关闭扩散，保留静态focus/pressed反馈。
