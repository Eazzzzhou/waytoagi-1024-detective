# 素材工具接入参考

[可移植配置](mcp.portable.json)登记了frontend-shadcn、frontend-magicui及需凭据的frontend-21st。配置、安装状态和mcp-verification.json均是原收藏环境记录，不代表当前机器安装或调用成功；实际能力以会话提供的工具为准。

registry-workspace只用于检索；采用组件时核对[registry配置](registry-workspace/components.json)，按目标工程需要合并，不直接在收藏目录安装。MCP不改变组件许可或免费范围。

需要账号的服务由使用者在自己的环境配置凭据，不提交密钥。实际权限、额度和计费不在此固化；官方入口：[shadcn](https://ui.shadcn.com/docs/mcp)、[Magic UI](https://github.com/magicuidesign/mcp)、[21st](https://21st.dev/magic/console)。使用前核对当前官方说明，当前项目优先复用已有组件。
