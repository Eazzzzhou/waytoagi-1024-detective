# 作品集灵感

收藏于 2026-10-21。以 Three.js 为起点，探索互动视觉、创意网页与趣味小站。

| 网站 | 看什么 |
|---|---|
| [Three.js](https://threejs.org/) | JavaScript 3D 库官网及作品入口，作为本次收藏的起点。 |
| [Mesh3D](https://mesh3d.gallery/) | 集中收录 Three.js、WebGL 与实时 3D 互动网站，适合寻找作品集和沉浸式网页灵感。 |
| [Experiments with Google](https://experiments.withgoogle.com/) | 艺术、音乐、科学与交互实验的综合档案；官网保留 1,605 个历史实验。 |
| [Chrome Experiments · WebGL](https://experiments.withgoogle.com/collection/chrome?tag=WebGL) | Google 实验合集中的 WebGL 入口，偏 3D、粒子与图形互动；与总档案有内容重叠。 |
| [SAEL Lab](https://lab.sael.net/) | 精选创意网页、交互界面和 Three.js 世界，适合探索独立创作者的实验作品。 |
| [The Useless Web](https://theuselessweb.com/) | 点击按钮随机前往古怪、搞笑或单纯好玩的独立小站。 |
| [Neal.fun](https://neal.fun/) | Neal 的网页游戏与互动作品合集，适合参考简单概念如何做成可玩的网页。 |
| [Chrome Music Lab](https://musiclab.chromeexperiments.com/) | 浏览器里的声音、节奏与作曲互动实验，适合体验音乐可视化和即时反馈。 |

优先逛 Mesh3D 找 3D 视觉灵感；逛 Google Experiments 找跨领域创意；逛 Neal.fun 和 The Useless Web 找趣味玩法。

这些是浏览与灵感入口。复用具体作品的源码、图像或音频时，分别核实原作者许可。Google Experiments 是历史档案，部分旧项目可能失效。

也可双击上级目录的“打开收藏.html”，选择“作品集灵感”分类。
