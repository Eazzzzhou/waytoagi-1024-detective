# 附录 B｜展示口径长什么样

> **虚构口径样例，来源均为假。** 沿用附录 A 的示例产品 P。下面不是真实价格、引语或用户反馈，不能计入 D2 的两个真实示例。丙需用真实证据另交一页口径与两张示例卡。

## 四类内容标签

| 标签 | 如何表达 | 虚构示例 |
|---|---|---|
| 事实 | 可定位并限定核查范围 | “示例获取时，定价页列免费套餐每月 50 次请求（E5）。” |
| 官方宣称 | 明确归属，不冒充独立实测 | “官方称其在某基准领先（尚未独立核验）。” |
| 使用者观点／报告 | 说明谁、何时、何种场景 | “alpha 报告免费套餐无法导出（E1）；beta 报告更新后成功（E2）。” |
| 归纳 | 说明依据及局限 | “基于 E1/E2 两条报告，导出争议可能与版本有关，尚不能确认。” |

一句包含不同性质内容时拆开标注；不要把混合句强行贴成事实。原文／译文是表达形式，与上述内容性质分别标识。

**原文（虚构 E1）**：“I could not export on the free plan.”  
**译文（不是原话）**：“我在免费套餐上无法导出。”  
**归纳**：一位作者报告过导出失败，不代表所有用户当前都失败。

官方宣称与第三方使用／实测分栏；同源转载合并说明；没有引文不写“很多人说”。观点有正反材料就并列，只有一边就如实说明，不凑正反平衡。

## 同一产品，两种回答

### 客观搜查卡（虚构）

**问题**：“帮我查一下 P 免费版能否导出。”  
**回答**：当前材料尚不能确定。E1 报告失败，E2 报告十月更新后成功；E3 与 E1 同源，不增加独立支持。  
**事实**：示例定价页 E5 列每月 50 次请求，与导出能力不同。  
**缺口**：缺 E1 具体版本与官方更新说明；E4 读取失败。  
**出处**：原文和占位链接形状见[附录 A](附录A-案例样例.md)，全部为假。

### 适配建议卡（虚构）

**问题**：“我零基础，想做自动化，每月预算 50 元，而且必须导出，P 适合我吗？”（虚构用户条件）  
**共同依据**：复用 E1—E5，不新增未经核实的产品事实。  
**相关约束**：必须导出；当前导出证据冲突。零基础上手门槛、自动化能力和付费价格尚无可靠材料。请求额度不等于人民币价格，预算是否够用不能推断。  
**建议档位**：证据不足。先确认当前导出与所需自动化能力，再判断适配；不能基于未知价格承诺在预算内。

四档仅供适配建议：值得一试／有条件值得／不建议／证据不足。客观搜查直接回答问题，不要求推荐档位。

## 自检三问

1. 读者分得清原话、译文和归纳吗？
2. 真实交付中的结论能回到原句与链接吗？
3. 还没查清的内容，读者看得见吗？
