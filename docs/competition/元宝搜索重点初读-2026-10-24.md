## 赛题与交付

主题是“少点幻觉，多点搜索”，做一个会查的 AI。网页、机器人、Skill、应用、小游戏均可。官网要求搜索为核心：“去掉元宝搜索，作品就转不起来”。不碰时政和涉及个人的消息。

## 元宝搜索实际提供什么

元宝搜索（wsa）是检索服务，接口返回排序后的网页数据；回答生成及判断须由调用方完成。元宝 App、元宝搜索 API、回答模型不能混为一谈。

API KEY 接入：POST https://api.wsa.cloud.tencent.com/SearchPro ，Bearer 鉴权，JSON 请求体。腾讯云标准接口则是 wsa.tencentcloudapi.com，Action=SearchPro，Version=2025-05-08。支持 MCP，比赛接入指引也提供 OpenClaw Skill 入口。

核心能力：

| 能力 | 字段和限制 |
|---|---|
| 查询 | Query |
| 搜索类型 | Mode：公开网页、优质权威垂直信源、混合；极速版不支持 |
| 定向找源 | Site：一次指定一个域名；排除最多五个域名。对 VR 结果不生效 |
| 领域搜索 | Industry：gov/news/acad/finance；极速版不支持 |
| 时间过滤 | Freshness；区间方向的文字描述与示例存在不一致，落地时须实测 |
| 结果条数 | Cnt：10/20/30/40/50；极速版不支持此参数 |
| 证据字段 | title、date、url、passage；非极速版有动态摘要 content |
| 排序分数 | score 是相关性，0–1；不是事实真实性概率 |
| 权威度 | authority_level 为 0–5，仅旗舰版提供；也不能直接等同真实性 |

Response.Pages 的类型是字符串数组，每条字符串内部为 JSON；接入时需要逐条解析。content 明确是动态摘要，不应当作已获取的完整正文。

版本：极速版与标准版支持个人/企业账号；旗舰版限企业认证；三种不能同时使用。比赛接入指引标价分别为每千次 14/20/26 元。活动宣传提供 6000 次免费搜索，邀请码仅在侦探群发放；账号实际额度及有效期未实测。

## 对后续技术方案的直接影响（设计判断）

建议优先评估标准版：相比极速版，搜索模式、领域与结果数量控制更适合多轮查证；不以旗舰版专属权威度字段作为系统必需条件。

后续方案应围绕：问题拆解 → 元宝多轮检索 → 获取关键原文 → 识别转载和共同源头 → 逐条判断支持/反驳/不足 → 冲突追查 → 输出带出处结论。

多模型可承担独立证据判断和复核，但共同引用同一错误源头时，模型意见一致仍不能算独立验证。搜索得分高、网页数量多、模型投票多数，都不能直接作为“事实为真”的判定规则。检索失败、正文取不到与查证后证据不足需要区分。

本轮尚未开展算法文献/GitHub 项目比较，未选择模型、依赖或置信度公式，也未声称方案已验证。下一步算法设计须补齐这些研究与小规模真实案例评估。
