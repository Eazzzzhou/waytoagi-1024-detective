# A2 v4 研究调度与集成

2026-10-25；基线 af3867e；独立目录 waytoagi-1024-detective-a2-v4、分支 a2/research-engine-v4。此文先记录可检查实现，真实集成与对照结果按实际运行补充；不把测试替身当成外部服务成功。

## 状态与模块

`src/server/research/engine.ts`承载研究生命周期；`state.ts`维护不可删除的问题账本、候选去重与分层、覆盖和正式推荐策略；`budget.ts`执行时间/工具/模型/token约束；`verification.ts`逐主张核查并生成经过原句复查的直接回答和综合分析。handler最终只装配真实采集/文档能力和选择引擎。

账本永久保留原始问题，初始必答字段须用用户原文连续子串锚定；后续可加研究子题，不能删用户必答项。覆盖必须关联实际支持主张和READ片段，官方字段需要官方材料，使用报告不能靠教程或营销覆盖。缺少材料时记录本次覆盖不足，不把它解释成世界上不存在。

候选来自实际搜索记录及保存文档中的真实链接。按关键未答项、当前争议、其他补充分层，再比较来源类型和新视角；排序只用于调度，不是可信度。一个论坛不同评论不因同host自动合并；没有已知来源关系仍保留独立性未知。正式用途推荐策略独立于事实查询，至少3组已确认独立真实报告且跨2个站点；不足仍输出客观事实与限定分析。

完整文档由A1读取并保存在本地内容存储。调度器验证其documentId/version、块范围和UTF-16区间，引用hash与保存文本完全对应。同页换焦点走SELECT和排除已选区间，不重新下载；重复focus直接记NO_GAIN。按用户最新要求，搜集增量只看新增保存文档/原文片段；不在搜集循环中提取主张、核查真假或总结结论。确定性关键词选段直接复用reader.select；表格命中行另附连续表头片段。完整原文照常保存，不以选段替代全文。文档版本为内容与解析链hash字符串，非递增整数。

## 预算和存储

默认FACT 120秒/6搜索调用/8文档；STANDARD 360秒/18调用/24文档；DEEP 600秒/30调用/40文档，分别预留35/75/120秒。搜索入口各计一次，下载失败也计；缓存选段、模型、输入输出token和无usage调用分开计。实际价格未配置，不计算虚构金额。模型格式重试在v4由上层局部修复管理，不藏在未计量循环内。

Worker默认660秒、租约心跳保留。若运行配置更短，实际研究预算须提前收缩并记明限制，不能被Worker先杀掉。API支持researchDepth=AUTO/FACT/STANDARD/DEEP，数据库新增默认AUTO列及检查约束；AUTO幂等hash保持历史兼容，显式深度不同不能复用旧幂等请求。

新快照增量携带research.schemaVersion=2.0.0及可选documentReference；已有contractVersion=1.0.0历史快照不改写。全文不重复放入每个快照，存文档manifest定位索引、任务、候选、实际动作与成本。旧v3调查审计继续按旧约束读取。

## 核查和回答

搜集结束后才进入一次独立核查阶段；核查结果不再驱动本轮搜索。搜集调度仅决定查询、未读来源和缺少哪类原始材料，不以SUPPORTED或争议解决作为结束条件。输出逐项safeParse，结构错误只修该主张一次；失败保留有效兄弟主张。可比较支持与反驳分别保留，不用多数票判断。总结器仅接收已核验主张与条件；综合句再次用其原句核查所有断言，未完成或越界段落不发布。引用原句由程序装配，不由模型改写。

## 研究依据与评估冻结

先复用项目Worker、Postgres、Zod4与原生AbortSignal，没有引入AI SDK或Python研究服务。设计参考Jina候选池/全文缓存/缺口队列、dzhng主题展开，未复制外部代码；既有版本/许可证比较见共享《开源研究-搜索调度-v4》。不复制Jina同host奖励及强制回答，不迁移AI SDK4/Zod3。

独立researcher核对[Node v24.15.0 AbortSignal](https://nodejs.org/download/release/v24.15.0/docs/api/globals.html#static-method-abortsignalanysignals)、[Zod JSON Schema](https://zod.dev/json-schema)及[Jina固定提交](https://github.com/jina-ai/node-DeepResearch/blob/fd323b521a51264d497bec333bfb997da1bf3210/src/agent.ts)。本机Node24与锁定Zod4.6.7沿用，不升级。Readability/jsdom/playwright-core由A1验证并提出版本，A2统一锁定依赖。

非算法实现者冻结[评估参考](../research/v4-evaluation/reference-v1.md)：S0–S7共36必答字段，S8单列能力路由；参考不进入生成提示。采用COMPARISON预设180秒/6搜索调用/10文档/45秒最终预留，两版本各自实际消耗另记。长预算单列，不把额外耗时带来的覆盖提高全部归因于算法。
