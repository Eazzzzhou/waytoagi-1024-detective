# 三人职责分工与协作边界

本文件以当前用户指定的甲／乙／丙职责为准，并统一说明真实业务接入与前端消费。`reference/队友交接包/` 保留的历史策划是来源资料，不代表其中旧分工、T0、候选或示例已成为当前真实交付。公共工程验收不代表真实搜索和核查已完成。

## 分工总览

| 负责人 | 负责 | 不在本次公共工程内实现 |
|---|---|---|
| 乙（公共工程，本轮协助对象） | 框架、共享契约、Prisma/迁移、队列、Worker 生命周期、API、验收、D1 人工核查案例准备 | 搜索／核查算法、凭空案例、替甲对外调用、复杂前端 |
| 甲 | 产品身份解析、元宝真实搜索、原文获取、模型调用、主张提取、来源／引用核查、客观回答生成 | 改写租约归属机制、跳过事务发布、把搜索摘要当作已读原文 |
| 丙 | 前端体验与结果表达、接口消费、独立复核和理解验证 | 前端直连数据库、前端保存密钥、模拟成功和进度、修改证据事实 |

## 稳定交接面

- `src/contracts` 是唯一可执行数据契约，大家从同一份代码导入，不各自维护同名接口。
- 甲在 `InvestigationHandler` 返回 COMPLETE 或 AWAITING_CONFIRMATION；失败抛出可解释、已脱敏的 TaskFailure。只调用 context.setStage，不自行改任务状态或存最终结果。
- 丙只调用 [HTTP接口与错误码说明](HTTP接口与错误码说明.md)，按真实状态和快照表达。不能通过计时器推演进度，也不能把错误状态解释成“未找到讨论”。
- 乙维护 [公共工程验收记录与结论](公共工程验收记录与结论.md)、迁移和基础设施测试；正式提供方不可用时保持明确失败，不将夹具接入正式 handler。

## 数据与评审

新回答增加 quotes 引用原句字段：新写入必填，历史 v1 只读兼容；证据快照仍是 1.0.0。请同步共享契约后再接入。改变字段含义、状态语义、独立来源计数或错误重试语义时，先更新契约与文档，再由三人共同对齐。

甲提交真实失败和访问受限材料，丙保留相应状态并独立复核，乙用 D1 的原文与预期行为验证公共存储和表达。A-01、B-01、C-01 草稿已建立，待乙确认。规范、模板和评估标准见 [D1 案例入口](../cases/README.md)；不得用 tests/fixtures 或历史占位案例替代。

## 交接标准的范围

公共工程验收通过意味着可安装、可迁移、可靠入队和执行、明确失败、验证后持久化与展示；不意味着真实搜索、模型核查、独立来源判断、补查或建议已经完成。外部 API 允许因崩溃而重复调用，数据库发布通过令牌和幂等约束防止重复。

## 丙需要使用的 HTTP 接口

- POST /api/investigations：带 Idempotency-Key，202 后跳到调查 ID。
- GET /api/investigations/:id：真实状态、阶段、错误、身份确认需求、重试规则与快照 ID。
- POST /api/investigations/:id/identity：只允许等待中的当前尝试确认。
- POST /api/investigations/:id/retry：只允许符合预算和错误规则的失败任务恢复。
- GET /api/snapshots/:id：经校验的历史或当前不可变快照与回答，缺失 404。

只从 src/contracts 导入 Schema 与推导类型，不在前端复制一套 DTO 或读取数据库。接口细节见 [HTTP接口与错误码说明](HTTP接口与错误码说明.md)。

| 内容 | 正确表达 |
|---|---|
| 官方事实与官方宣称 | sourceType=OFFICIAL 只说明来源；contentKind=OFFICIAL_CLAIM 必须显示官方宣称，不能当独立实测 |
| 第三方报告 | 标出作者、使用场景、版本和时间，不能推为所有人都成立的事实 |
| 原文与译文 | 独立标签与字段；译文不冒充原话，quotes 只能匹配 originalExcerpt |
| 证据不足 | 显示已有事实与明确缺口，不凑材料，不强制给推荐档位 |
| 身份歧义 | 显示确认原因和真实依据输入；没有用户操作不自动确认 |
| 失败与历史快照 | 明确失败原因；已有快照按其版本与生成时间展示，不能称为本次最新成功 |

## 丙的组件与展示规范

当前只有首页和调查详情两个页面，使用 Next.js App Router、TypeScript、CSS Modules，无组件库或动画依赖。所有任务与结果通过真实 HTTP API 获取，详细请求／响应见 [HTTP接口与错误码说明](HTTP接口与错误码说明.md)，共享 Zod 与类型从 `src/contracts` 导入。

## 组件接口

| 组件 | Props / 职责 |
|---|---|
| AppShell | `{children}`；案卷标识、本地工作区、发起调查入口、响应式外壳 |
| NewInvestigationForm | 无 props；输入校验、同一问题的重试沿用同一提交键、防重复点击、202 后跳转详情 |
| InvestigationDetail | `{investigationId: UUID}`；状态请求、非终态轮询、刷新、快照读取、重试控制；切换 ID 时由路由 key 重建，避免混用不同调查的数据 |

## 状态展示规范

| 数据状态 | 展示与行为 |
|---|---|
| PENDING | 排队中；说明等待 Worker 或自动退避，不能编造开始时间或队列位置 |
| RUNNING | 调查进行中；只显示已保存 stage，不计算百分比，不按计时器切换阶段 |
| AWAITING_CONFIRMATION | 显示 reason 与身份表单；不宣称正在后台继续执行 |
| SUCCEEDED | 展示已保存快照及回答，保留快照版本与时间 |
| FAILED | 显示业务错误 code/message；只有 retry.allowed 为 true 时允许重试，显示不可重试原因 |
| CANCELLED | 显示已取消；当前没有取消按钮或取消 API |

正常状态每两秒读取一次，PENDING/RUNNING 之外停止轮询。等待确认由提交成功或显式刷新后继续读取。网络失败不改写后台状态：保留上次成功数据并提示其更新时间，最多自动重试三次，随后由刷新按钮恢复。组件卸载会 Abort 请求并清除定时器。

执行阶段统一使用 `STAGE_LABELS`：任务已创建、解析产品身份、联网检索、获取来源原文、核查主张、整理回答、结果已保存。阶段更新时间来自数据库。日期统一显示上海时间并明确标注，ID 使用等宽字体。

## 回答、引用与证据

- 回答 body 作为纯文本分段保留换行。不得直接使用 dangerouslySetInnerHTML；以后如需 Markdown，必须禁用原始 HTML 并安全处理链接。
- 引用 marker 与 evidenceIds、claimIds 按原映射显示；来源链接跳到同一快照的原文区域。不能按相似句子自行寻找替代证据。
- 原文、译文、验证理由、来源元数据分开。官方材料、官方宣称、第三方材料、使用者报告按已有标签区分，不能把“有人说过”变成普遍事实。
- 每条来源显示直达 URL、作者、发布时间、获取时间、原文定位和读取状态；未知字段明确为“未知”。READ 以外的状态不显示伪造原句。
- 来源独立性按已保存判断显示，保留理由；共享上游不按多个独立支持计数。外链只允许契约接受的 HTTP(S)，新窗口链接带 noopener/noreferrer。
- 主张逐条显示验证状态、理由、适用范围及证据关系；冲突保留处理情况，缺口明确范围。没有缺口记录不等于不存在未知信息。
- 没有快照时只显示空状态；没有回答、证据、主张时分别说明，不注入样例卡片。快照读取失败不以空列表冒充正常结果。
- 页面不自行生成适配建议，也不自动应用推荐四档。补查与 Advice 仅有文档预留。

## 身份确认与重试

身份依据的来源、原句和获取时间来自真实数据或用户填写。未知版本／套餐为 null；不能自动写入当前时间伪装为获取时间。表单按用户本机时间输入，提交时转换成含时区 ISO 时间。

提交身份或重试时携带状态响应中的 expectedAttemptCount；409 表示记录变化，提示刷新，不能在前端强制改状态或循环自动重放确认。API 的手动重试预算最多两次，每次只增加一次执行机会；不可重试的缺配置错误不开放按钮。

## 视觉基线与验证

使用 design-taste-frontend 的 app-screen 规则，方向 **Achromatic ledger**，seed **508062102**。问题分别是：首页“要核实什么”，详情“执行到了哪里、依据能否复核”。

界面采用报告账册的克制层级：浅蓝灰底、白色工作面、近黑主按钮、24px 标题、14px 正文、12px 元数据，颜色主要用于失败状态。Geist 与 Geist Mono 本地加载，中文使用系统中文字体；Mono 仅用于 ID／错误代码，字体许可随 public/fonts/OFL.txt 保存。案卷文件夹标识与原文／引用的成组排版是产品特征。

首次抽取的 Icon rail 与只有一个导航入口的实际功能不符，因此重抽一次 shell 为 Open plane；未引入虚构导航。首页引导说明不做与表单同排的空卡片。桌面 224px 侧栏、32px 页边距；1100px 以下折为顶部导航，640px 以下单列、16px 页边距、44px 点击目标。保留键盘焦点、真实 label、跳到主要内容、可读禁用原因和请求错误提示。

新增页面不能靠演示数据撑满：首页下方的留白是未提交状态，没有指标、客户或证据可填。纯文本证据不需要背景图、装饰插画、图表或进度动效。视觉与交互验证使用隔离测试 schema，所有测试材料明确标识，不属于正式结果。
