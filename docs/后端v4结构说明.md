# 后端结构说明

v4 后端已并入根工程；前端位于 `src/app` 与 `src/frontend`，后端不再单独维护目录。

```text
src/
├── app/                 Next.js 根布局、全局样式与 HTTP Route Handler 适配层
│   └── api/             只解析请求并委托 src/server/http
├── frontend/            正式调查界面、演示样稿与客户端 HTTP 适配
├── contracts/           Zod请求、快照、证据、回答、建议及研究审计契约
├── server/
│   ├── http/            创建、详情、身份确认、重试、快照、建议HTTP业务
│   ├── investigation/   引擎装配；legacy-v3保留旧引擎对照
│   ├── research/        v4搜集调度、预算、原句选段及独立核查
│   ├── retrieval/      元宝/Tavily等搜索、网络访问、全文缓存与定位
│   ├── models/          主模型调用与用量记录
│   ├── verification/    通用核查与来源分组
│   ├── queue/           PostgreSQL调查／建议任务队列、租约、重试和配置
│   ├── storage/         Prisma数据库连接、调查与建议持久化
│   ├── identity/        产品身份识别
│   └── recommendation/  推荐策略边界
└── worker/              独立进程入口、调查／建议领取、心跳、执行和原子发布

prisma/                  数据模型和七份增量迁移
infra/                   本地PostgreSQL开发/测试容器
config/                  Worker TypeScript、单元/数据库测试配置
scripts/                 迁移、采集、调查导出和隔离运行检查
tests/                   后端测试、夹具、隔离数据库支持
.env.example             无真实密钥的配置模板
```

流程：HTTP提交 → 数据库调查/任务 → Worker领取 → 查询、抓取、缓存全文和原句 → 结束搜集 → 独立核查与回答 → 原子保存快照 → HTTP读取。

建议流程：HTTP提交 `AdviceRequest` → 绑定不可变快照与真实条件 → 建议 Worker 领取 → 执行适配器（尊重取消信号）→ 受执行令牌保护原子发布 → HTTP查询。建议状态与结果共用查询接口，条件不足和系统失败分开；真实生成未配置时明确失败，不返回虚构建议。

搜索层只做信息搜集，不逐页生成总结或穿插真假核查。全文和原始字节保存在根工程 `.cache/source-documents-v4/<调查ID>/`，快照保存文档版本、原句范围和哈希；缓存不提交Git。数据库保存任务、执行状态、证据快照和回答。

## API

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | /api/investigations | 创建调查，支持AUTO/FACT/STANDARD/DEEP深度 |
| GET | /api/investigations/:id | 查询状态和结果指针 |
| POST | /api/investigations/:id/identity | 提交身份确认 |
| POST | /api/investigations/:id/retry | 有限手动重试 |
| GET | /api/snapshots/:id | 获取不可变快照和回答 |
| POST | /api/investigations/:id/advice-requests | 幂等创建建议任务，202返回建议任务ID |
| GET | /api/investigations/:id/advice-requests/:requestId | 查询建议任务状态及结果 |

API与Worker使用相同数据库；测试使用另外的测试数据库及随机schema。`RESEARCH_ENGINE_VERSION=v3`可切换旧引擎，默认v4；`RESEARCH_BUDGET_PRESET=COMPARISON`只用于同预算对照。v4默认FACT/ STANDARD/DEEP为120/360/600秒，Worker默认660秒。可通过`COLLECTION_BROWSER_EXECUTABLE`指定本机Chrome可执行文件以读取需要JS渲染的公开网页，不下载浏览器、不绕过登录。

调查代码来自 v4 分支 `5bf59c6`，建议通路来自根工程，两者已合并为同一套 `src/contracts`、`src/server`、`src/worker` 与 `prisma`。前端通过同源 HTTP 接口及 `src/contracts/` 数据契约对接；不再维护第二套后端。

`src/server/investigation/legacy-v3.ts` 仅用于同预算对照，不是第二套产品后端。退役条件：最近一次 v3/v4 对照已完成并记录、无未关闭复现项、且 v4 已覆盖对照涉及的入口；满足后删除 `legacy-v3.ts`、`RESEARCH_ENGINE_VERSION` 分支和对应测试。未满足前不要删除，也不要在新功能中继续扩展 v3。
