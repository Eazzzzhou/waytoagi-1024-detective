## 修复与整理

- 新增新写入回答的引用原句校验，逐字符匹配已保存 Evidence；证据 ID、主张 ID、快照归属和已读状态仍须成立。旧 v1 回答只读兼容，不改历史数据。
- 修复数据库／任务配置初始化异常绕过 JSON 响应的问题；修复结构合法但存储关联不一致的错误分类。
- Web 不再读取 Worker 专有心跳／轮询参数；Worker 生命周期独立，正式 handler 仍明确缺配置失败。
- 补齐 Bearer、Basic、引号密码与 URL 用户信息脱敏。
- 存储测试也迁入随机 schema，避免依赖测试库 public 中“没有其他数据”的假设；测试库与业务库同名时拒绝，即使主机是 localhost / IP 别名。
- 测试配置、Compose、运维脚本、测试宿主、活跃文档和历史参考已按 [项目目录结构与文件迁移记录](项目目录结构与文件迁移记录.md) 归并，原迁移和业务模块边界保留。

## 关键真实数据库用例

- 原子创建与入队、同键重复／不同参数冲突、Worker 领取后缺配置失败、API 再次读取仍保存相同错误。
- 两个独立 Worker 竞争只有一个合法领取；SKIP LOCKED 跳过已锁行；数据库时间心跳与执行硬截止；等待行锁后过期不能续租。
- 实际杀掉子 Worker、实际终止数据库活动连接后回收；旧令牌不能更新阶段、续租或发布；重试预算耗尽进入终态。
- 回答写入期间租约过期时快照／回答／状态整笔回滚；并发重复完成只创建一个快照和回答。
- 数据库拒绝普通 UPDATE/DELETE 覆盖快照；版本与父快照归属有效；非法结构经正式 Repository 不能入库，损坏 JSONB 不能安全读取。
- 引用证据 ID 必须存在；原句被改写、换成译文或多加空格会被拒绝；损坏原句引用的存储记录经 GET 返回明确错误。
- 身份确认仅限等待中的当前尝试，竞争提交只有一个 202；手动重试仅允许符合错误与预算规则的终态任务，保留全部历史执行记录。

## 独立进程与测试性质

test:runtime 使用真正的 Prisma migrate deploy 在全新隔离 schema 应用迁移，启动生产 Next Web 和独立 Worker 进程。Worker 只使用正式 runWorker / investigationHandler，不注入成功处理器；IPC 仅用于跨平台发送 supervisor AbortSignal，验证优雅关闭和数据库断连。实际网络检查 202、405、404、配置错误 503 JSON、同源幂等提交及失败持久化。

正向快照／回答夹具只用来测试存储、引用一致性和显示，不证明任何产品事实；生产源码导入边界测试禁止导入 tests。公开入口没有 Mock 模式。此前浏览器验证的截图与数据属于隔离测试，不属于真实产品调查结果。
