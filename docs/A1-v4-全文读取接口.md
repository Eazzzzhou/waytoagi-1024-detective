```ts
import { createDocumentReader } from "../retrieval";
const reader = createDocumentReader({ signal, timeoutMs: remainingMs,
  storageDir: localDocumentStore, // 调查/本地内容存储，不能随历史快照删除
});
const { document, cacheHit } = await reader.read(url, {
  signal, timeoutMs: operationRemainingMs, render: "auto",
});
if (document.status === "READ") {
  // 理解材料读取 document.text、blocks、tables、metadata；不是只看短引。
  const fragments = reader.select(document, { query: currentGap, maxFragments: 8, maxChars: 300,
    exclude: previousFragments, signal });
  const evidence = fragments.map(fragment => reader.toEvidence(document, fragment, { officialWebsite }));
  // Evidence 保持既有格式；另保存 fragments 的结构化 document reference。
}
const restored = await reader.load(documentId);
```

`read(url,{refresh:true})` 明确新取得一版；默认同一 factory 内规范 URL 缓存成功文档，并合并并发请求。失败不永久缓存，是否重试由 A2 决定。`render:"always"` 强制选择独立渲染取得；`never` 禁用渲染。跨 factory 不自动采用旧资料，`load(id)` 是显式历史读取；问现价/配额时不能无提示用旧缓存。默认存储 `.cache/source-documents-v4`，演示与历史保留应由 A2 显式配置稳定内容存储目录并保留。

所有当前请求支持 signal；总预算允许 1..900000ms，A2 仍是调查截止/Worker 生命周期的拥有者。原 `createCollectionProviders` 的 300000ms factory 上限同步放至900000，避免复杂研究被旧闸门拒绝；未改变其兼容便捷方法的旧语义。

## 材料、定位与错误

- `SourceDocument.status` 是 READ/FAILED/RESTRICTED；原文为空、挑战、非支持媒体、请求超限均保留真实失败，不拿“工具 success=true”替代原文检查。单文档失败不会改变其他文档。
- 保存 requestedUrl、finalUrl、retrievedAt、contentType、原始字节 SHA-256 `rawHash`、完整规范文本 SHA-256 `textHash`、解析器/规范化版本、结构块/表格单元格/多评论/来源链接，以及 raw/text/manifest 文件路径。`load` 验证文本、原始取得链与块范围。
- `DocumentFragment` 明确 documentId、documentVersion、blockId、start/end（该版本全文 UTF-16）、exactText、fragmentHash、原URL、locator和context。每片段属于一个块的连续原文，最多300字符；表头和目标行不在同一窗口时分别引用，不拼接。
- `toEvidence` 验证版本、块范围、原句和 hash，把旧 `Evidence.contentHash` 设置为 **片段** hash。全文与原始文件 hash 不混用。locator 带原URL、文档版本、块、范围、片段及全文 hash；持久片段可通过保存的 source.txt 重算。
- 文本规则 `source-text/v1`：DOM 实体解码、普通块压缩空白；代码保留换行/缩进并统一 CRLF 为 LF；块之间两个换行。所有坐标都指向最终保存的同一文本，不用 Readability/Trafilatura/Crawl4AI 转换文本的坐标。
- Readability 克隆 DOM、识别正文与元数据，既不执行脚本，也不下载资源；原 DOM 独立提取表格、代码与评论。Readability 的总结不是证据。超4000块明确 TRUNCATED，原始材料仍保存；默认单响应8MB，超限是失败，不静默截断。
- HN 通过官方 Algolia item JSON 保存原帖与多评论，保留实际作者、评论ID、父子与时间，评论原URL指向实际 comment ID。story 上游单列链接，不自动赋给每条评论。未知作者/独立性/上游不补造。
- GitHub blob 页沿实际 Raw 链接读取原始文件，保留请求的 owner/repo/ref/path、最终原始URL与两份取得 hash；不从主分支名猜具体 commit，也不把 UI 壳当文件正文。
- 文内公共链接保留文字、所属块、原始定位；canonical/story上游与普通LINK分开。链接发现只产生候选，不自动确证上游归属或独立性；导航/危险协议/私网链接不进入正文候选。

`reader.journal.actions` 分别记录 READ/SELECT/LOAD、cacheHit、文档ID、实际耗时、状态、片段hash和错误；`journal.httpAttempts` 包括跳转/浏览器资源的公网请求、起止、requestSent、HTTP状态/失败与 documentId。requestSent表示调用req.end，不保证服务器收到；跳转外层耗时有重叠，不应直接相加。无认证头/密钥或完整请求体。父取消前先保存失败取得和已完成记录，再抛出；A2在catch/finally保存journal。

## JS 读取

给 reader 传 `createSafeBrowserRenderer({executablePath})`，或设置 `COLLECTION_BROWSER_EXECUTABLE` 指向本机 Chrome/Edge。使用独立无登录态的 headless context；不安装浏览器，不访问用户浏览器会话。所有HTTP资源经现有 Node 公网检查与固定IP传输 fulfill；阻止service worker、WebSocket、写请求及无需的图片/媒体。不绕过登录/验证码，保留证书检查/CSP。有限请求数/字节/时限，失败如实返回。STATIC与RENDERED原始取得分别留存、分别hash，渲染后的材料有独立解析版本。
