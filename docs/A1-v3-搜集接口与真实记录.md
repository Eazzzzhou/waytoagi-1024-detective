## 调用

```ts
import { createCollectionProviders, unresolvedIdentity } from "../retrieval";
const p = createCollectionProviders({ signal, timeoutMs: remainingMs, question, maxSources: 6 });
// 上层 AI 决定 query、entry、读取目标；这里没有调查调度器。
const result = await p.execute({
  query: selectedQuery,
  entry: "yuanbao", // yuanbao | tavily | bing | hn
  maxReads: 2,
  // readUrls 省略：读取本批返回来源；[]：只搜索；也可给上层选定的公共 URL。
}, { signal, timeoutMs: 15_000, question });
// { retrievalRecords: RetrievalRecord[], evidence: Evidence[], diagnostics }
const identity = p.discoverIdentity(question, result.evidence); // 同步，无隐藏调用
// 或需要兼容既有调用方时：
await p.search(query, unresolvedIdentity(question), { signal }); // 元宝，identity 可省略
await p.searchSecondary(query, undefined, { signal }); // Tavily
await p.searchWeb(query, undefined, { signal }); // Bing RSS
await p.searchCommunity(query, undefined, { signal }); // HN
await p.fetch(url, { signal, question, officialWebsite: identity.officialWebsite });
```

`CollectionRequest`、`CollectionResult`、`SearchEntry`、`CollectionDiagnostic` 在 `src/server/retrieval/collection.ts`，由 `index.ts` 导出。没有更改共享契约。

`resolve(question, context?)` 仍可调用，但现在会真实执行一次元宝检索和最多三个原文读取，共享 factory 总预算及调用者 signal；这些调用全部记录在 `p.journal`。A2 已搜集材料时应优先用同步 `discoverIdentity`，避免重复搜集。七产品表已删除。确认依据是问题中的名称与新读取页面最终出版域名、标题相符；保留对应原文和时间。多产品比较、名称无法匹配、复合公共后缀等保守留 `UNRESOLVED`；不猜版本、套餐或法律所有权。未知身份不会阻止 `search`、`execute` 或 `collect`。身份发现不自动把旧材料升级为 OFFICIAL；带明确 `officialWebsite` 的读取沿用现有官方来源标注。

`collect(question, identity?)` 只保留为兼容便捷调用：元宝+Bing；不再在身份未知时提前返回，不再按问题关键字隐藏添加 HN。正式调查应使用上层选定的入口和查询。

## 错误、预算与来源链路

- 搜索摘要仅位于 `RetrievalRecord.returnedSources[].snippet`；只有真正读取的原文进入 READ Evidence。摘要、空壳、挑战页、非支持媒体不成为引文。
- `record.id → returnedSources[].evidenceId → Evidence.id/sourceUrl/originalLocation/contentHash` 保留链路。一次无效结果不会清空同批有效结果；无法表示为合法公共 URL 的结果在 diagnostics 保存序号、关联 record ID、阶段与错误，不复制潜在凭据。
- 单请求失败/超时返回 FAILED/RESTRICTED，后续来源继续；父取消和 factory 总截止仍抛出。`p.journal` 在异常后保留已完成搜索、原文、局部失败及已建立的引用链路；调用方应在 finally/catch 保存它。取消不代表没有材料。
- `journal.httpAttempts` 记录每个 HTTP 尝试（含跳转）的 ownerId（搜索或证据 ID）、URL、方法、开始/结束时间、requestSent、HTTP 状态、错误；不存鉴权头、请求体或密钥。DNS失败的 requestSent=false。跳转的外层耗时包括内层，请勿把重叠耗时相加当总时长。
- 去掉 fragment、常见 utm/点击跟踪参数，保留语义参数，再做同批 URL 去重。不同 execute 调用可以重新读取同一页面；这些读取和不同入口返回同 URL 都不是多份独立证明。已知 HN 上游保留，未知上游/独立性保持 null/UNKNOWN，由 A2 按主张做同源归并。
- 每 URL 保留一个最长300字符相关片段；规范化 DOM 文本、定位及 SHA-256 规则沿用基线。新增中文 n-gram 和表格行提取，短数值行不再因不足30字符丢失；表格上下文保留列头/模型信息。仍不执行 JS、不读 PDF、不支持非 UTF-8 正文。
