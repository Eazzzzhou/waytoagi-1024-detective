## 怎么调用

```ts
import { createCollectionProviders } from "../retrieval";
const p = createCollectionProviders({ signal, question, timeoutMs: 60_000, maxSources: 6 });
const identity = await p.resolve(question);
const record = await p.search(question, identity); // 仅元宝
const web = await p.searchWeb(question, identity); // Bing RSS，独立provider
const community = await p.searchCommunity(identity.name, identity); // HN，按问题价值调用
const item = await p.fetch(url, { question, officialWebsite: identity.officialWebsite });
// 或便捷采集，不写数据库和任务状态：
const result = await p.collect(question, confirmedIdentity); // {identity,retrievalRecords,evidence}
```

保留原接口的 `resolve(question, context?)`、`search(query, identity, context?)`、`fetch(url, context?)`，可选context为 `{signal?, timeoutMs?, question?, officialWebsite?}`。默认 identityProvider/retrievalProvider/sourceProvider 也可用。正式handler每任务创建factory共享预算；不要进程启动时创建后永久复用。默认总预算60秒、单请求15秒，最多12个不同来源原文、单响应2MB、3次跳转。父取消／总截止抛出给Worker；单请求失败返回真实状态。身份非CONFIRMED应走现有确认流程。

## 配置与重跑

见 [.env.example](../.env.example)。`TENCENTCLOUD_WSA_APIKEY` 或 `TENCENTCLOUD_WSA_APIKEY_FILE` 二选一；文件支持用户下载的CSV，须只含一个不同的 `sk-...` 密钥。本机已按用户授权配置文件路径到忽略的 `.env`，没有复制密钥到结果或文档。

本机DNS经TUN返回198.18/15虚拟地址，需 `COLLECTION_DNS_MODE=local-tun`；正常公网DNS部署留空。该选项仅允许域名映射的198.18/15，仍禁止直接私网URL、localhost、带凭据URL、非HTTP协议，逐次跳转重新解析并固定连接IP。不替代公开部署的网络出口策略。

`X_BEARER_TOKEN` 可选，支持给定帖子ID的X官方API读取；缺授权返回RESTRICTED，不读HTML壳冒充正文。未实现X搜索。`YUANBAO_IMPORT_PATH` 是可选半自动导入，启用后优先使用，必须精确匹配本次query；不能称自动搜索。

## 输出语义与限制

返回对象均过 `src/contracts` 校验，未更改共享字段。READ要求原句≤300字、定位、时间、hash；SNIPPET_ONLY的摘要仅在RetrievalRecord，Evidence没有原句；NOT_FETCHED没有尝试；FAILED/RESTRICTED保留真实原因，无伪原句。ADOPTED仅表示取到可交A2核查的原文，adoptionReason明确不表示已验证语义支持。

HTML原文经实体解码、压缩空白，定位含最终URL、DOM块选择器／序号和规范化文本UTF-16区间。它不是原HTML字节，也不保证可见渲染。SHA-256仅对持久化 `originalExcerpt` UTF-8计算，可独立重算。HN定位实际评论JSON字段与comment ID。未知作者、发布时间、语言、版本、套餐与独立性留null/UNKNOWN，不拿HTTP时间当发表时间；不将所有评论自动当使用报告。正式提供方不读cases/、tests/或历史研究作搜索回退。

官方证据统一设置 `originGroupId=official-publisher:已确认主域`（共享托管含产品路径），归并同出版方子域／语言页；采集层独立性仍UNKNOWN并说明这不是独立实验，由A2做主张级同源判定。
