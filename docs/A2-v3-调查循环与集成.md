# A2 v3 调查循环与本机交付

2026-10-25，基线3c59299，独立分支a2/investigation-loop-v3。仅本机演示，不推送。真实集成验收记录另列，以下测试结果不是产品事实验收。

## 行为与边界

handler每次将实际搜索记录、保存原句、读取状态和剩余预算交给模型，只允许返回下一步SEARCH/READ/FINISH/CLARIFY。SEARCH每次一个查询，可选入口；首轮元宝必须实际参与，第二AI入口可用时同轮参与。READ仅能读取已经搜索发现的URL。后续SEARCH必须关联当时已取得的材料ID和明确缺口；重复相同入口/查询不执行。模型选择FINISH时，若探索预算允许，先提取主张并核查，将缺口返还下一次决策；材料增加后重建核查，材料不变则复用。模型可基于真实缺口补查或结束，最终仅使用当前材料对应的核查结果。

初始总预算180秒，其中45秒预留最终核查/回答，低于本机Worker的300秒；最多3轮搜索、10次决策、10次读取。模型决策单次20秒，搜索单次20秒，读取单次12秒；每次还受当前阶段剩余预算约束。最终提取最多15秒、核查最多25秒，且为回答保留剩余时间；真实测量后可调整。超时控制同时传递AbortSignal与竞速截止；已完成材料、局部失败和预算结束原因保留，不用Worker超时代替业务停止。不武断限制模型调用数。

verificationAudit.investigationLoop保存每次决策当时可见的材料ID、选择、缺口、原因、实际执行结果、搜集调用时间与状态。modelCalls包括失败/修复调用和取消分类。Schema拒绝执行决策引用未观察材料、超出硬次数、审计结果缺失等不一致。原句仍由程序复制，assertAnswerReferences逐字符核对；失败与摘要不升级为事实证据，同源沿用groupOrigins，上游未知保持UNKNOWN。

身份不是前置闸门。确有实质歧义时沿用AWAITING_CONFIRMATION/恢复，界面一个回答框；用户只澄清意图，不要求官网、原句或时间，也不将澄清当作证据。等待请求保存搜集材料和审计；恢复为新尝试，等待时间不计活跃调查预算。旧的已确认身份请求仍兼容。客观查询直接答；明确用途按用途核查，不主动改成职业建议或评级。

预算或服务失败时可以发布“未完成可靠回答”的快照和可查看材料，任务SUCCEEDED只表示已持久化这一真实有限结果，不等于结论得到证实。不会生成没有原句支持的兜底事实。

## 方案核对

先复用项目既有handler、原生fetch、Zod4和核查模块，无新生产依赖。2026-10-25核对[DeepSeek JSON模式](https://api-docs.deepseek.com/guides/json_mode)：JSON模式仍需本地结构校验、空输出/截断需处理；沿用已有适配器。

比较[vercel/ai](https://github.com/vercel/ai)的[停止条件实现](https://github.com/vercel/ai/blob/main/packages/ai/src/generate-text/stop-condition.ts)：当日main包7.0.153，Node>=22，仓库01:03Z仍有推送，Node24兼容要求满足。[LICENSE](https://github.com/vercel/ai/blob/main/LICENSE)实际为Apache-2.0文字（GitHub元数据NOASSERTION，不能只看元数据）。其工具循环需引入SDK/provider依赖并迁移现有调用与审计；[逐步超时问题](https://github.com/vercel/ai/issues/22073)、[断连后继续调用问题](https://github.com/vercel/ai/issues/23516)仍有相关开放讨论，不能假定框架自动解决本项目预算。选择扩展项目现有循环，仅参考公开设计，没有复制外部代码，因而无外部代码许可证增补。版本和问题状态为当日核对，不承诺未来不变。

[Node24官方AbortSignal文档](https://nodejs.org/download/release/v24.10.0/docs/api/globals.html#static-method-abortsignalanysignals)确认可组合取消。首次/docs/latest-v24.x地址被抓取规则拒绝，后改官方release文档成功；未升级运行时。Next客户端边界按本地安装16.4.3文档核对。澄清表单复用已有组件与样式，无新增素材或第三方前端库。

## 集成修复与限制

为保留模型名、版本与字段主语，表格摘录改为实际归一DOM中连续不超过300字符的窗口，短段落保留完整。定位、hash及逐字符引用检查保留；未拼接不连续句子，未把context或搜索摘要当原句。对结构无效的语义分析仅允许一次严格修复，引用语义不支持时降为未知，不能靠放宽校验通过。

默认第一轮实际调用元宝与Tavily官方Search API免密钥限额模式；额度耗尽需配置TAVILY_API_KEY。Bing/HN不是第二AI服务。未配置第二模型，不声称独立模型复核。模型决策reason仍可能夸大或误读摘要，保留以便审计，但不作为事实证据；最终程序停止说明仅报告实际执行，回答须经过原句核查。

180秒预算耗尽已用明确标记的测试替身验证：即使提供方忽略取消，也及时返回并保留此前证据。这不是实际外部服务持续180秒的压测。真实失败（403、证书错误、空页面、超字节预算）另见运行记录。动态页面、PDF等未增加专项解析，官方条款和用户报告可能仍取不到；结果应保留不足。
