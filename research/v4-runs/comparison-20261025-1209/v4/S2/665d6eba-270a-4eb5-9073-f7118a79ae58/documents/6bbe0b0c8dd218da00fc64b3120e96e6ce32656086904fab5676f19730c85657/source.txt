GitHub 为个人开发者提供三种 Copilot 计划，并提供专门的学生套餐，每种计划均依据您的编码习惯、对 AI 模型的兴趣以及所需的灵活程度来满足不同需求。

如何选择合适的计划

请考虑以下因素，以决定哪种计划适合您

刚起步？ 试用 GitHub Copilot 免费版，免费探索基础功能。

在学？ 选择 Copilot 学生版，免费获取高级功能。

经常使用 AI 编码？ 升级至 GitHub Copilot 专业版，获得更高灵活性及高级功能访问。

想要最佳性能和最多模型访问？ 选择 GitHub Copilot 专业版+，解锁 Copilot 的全部功能。

了解如何设置适合您的计划，请参阅 GitHub Copilot 计划入门指南。

企业限制
