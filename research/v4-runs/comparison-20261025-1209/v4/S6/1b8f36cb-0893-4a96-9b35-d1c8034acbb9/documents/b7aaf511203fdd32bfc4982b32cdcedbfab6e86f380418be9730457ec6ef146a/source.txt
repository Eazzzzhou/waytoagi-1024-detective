在 Visual Studio 中免费使用 GitHub Copilot

通过 GitHub Copilot Free，你可以通过提供对选择 Copilot 功能的有限访问权限，在 IDE 中体验 AI 支持的编码帮助。 使用 Copilot 免费版，你现在可以访问 Visual Studio 中所有 AI 集成功能，包括补全、编辑和聊天。

Prerequisites

若要在 Visual Studio 中开始使用 Copilot Free，需要：

Visual Studio 2022 版本 17.8 或更高

Visual Studio 中的 GitHub Copilot

在 Visual Studio 中开始使用 Copilot Free

使用 Visual Studio 版本 17.14 或更高版本，可以在 首次启动时激活 Copilot Free。 你也可以随时按照以下步骤从 Copilot 对话助手 窗口进行设置。

如果未登录，尝试使用任何 Copilot 功能时，将显示 开始使用 Copilot Free 对话框。

使用 Ctrl+\+C 在 Visual Studio 中打开聊天窗口。 还可以选择 IDE 右上角的 GitHub Copilot 图标，然后从下拉列表中选择打开聊天窗口以打开聊天。

在“聊天”窗口中，输入开始使用 Copilot 的提示。 将显示“开始使用 Copilot Free”对话框。

选择 继续使用 GitHub 或 继续使用 Google。

如果有现有的 GitHub 帐户，请在出现提示时登录。 否则，请按照步骤创建新的 GitHub 帐户。

完成后，会重定向回 Visual Studio。

Visual Studio 中的 Copilot Free 使用限制

Copilot 免费版提供数量有限的内联建议，并且对 Copilot 对话助手 和其他功能设有每月使用限额。 接近每月使用限制时，Visual Studio可能会显示使用情况警报。 达到每月限制后，你会注意到Copilot功能发生了变化。

在 IDE 右上角的 Copilot 徽章下拉菜单中选择 Copilot 使用情况，随时检查免费层状态。

下图显示了包含每月限制详细信息的“Copilot免费使用”对话框。

你可以随时通过从 IDE 右上角的 Copilot 徽章下拉列表中选择 Copilot 免费版状态来检查你的免费层状态。

还可以在 GitHub 帐户设置页上检查 Copilot Free 帐户的当前状态，。

已达到使用限制

如果达到Copilot免费版的使用限制，请等待每月重置或升级到另一个Copilot计划以继续使用Copilot。

有关不同计划之间的使用行为和模型相关指导，请参阅 管理 Copilot 使用情况和模型。

注释

截至 2026 年 4 月 20 日，GitHub Copilot Pro试用版已暂停。 如果试用，请切换到 Copilot Free 或升级到付费计划。 如需支持，请参阅 https://docs.github.com/en/copilot/get-started/plans。

充分利用 Copilot 免费版的技巧

在长时间聊天会话之前检查 Copilot Usage，以便可以决定何时节省使用情况。

保持例行提示简洁，并为聊天或编辑添加最多值的任务保留更大的提示。

若要自定义Copilot行为，请打开 Tools>Options>GitHub>Copilot启用或禁用要使用的功能。

如果Copilot的行为不符合预期，请确认正确的GitHub帐户在Visual Studio处于活动状态。

常见问题解答

谁可以访问 Copilot Free？

如果你有 EMU 帐户、通过组织获得 Copilot 许可证、现有 Copilot Pro 订阅，或作为学生、教师或开源维护者免费获得 Copilot Pro，则不可使用 Copilot 免费版。 有关最新信息，请参阅关于 GitHub Copilot 免费版。

我可以关闭补全以节省以后使用吗？

Yes. 你可以随时启用或禁用补全。 要启用或禁用补全，请从 IDE 右上角的 GitHub Copilot 徽章中选择“设置”，然后选中或取消选中“启用 GitHub Copilot 补全”。 还可以从 设置>选项访问它。

我可以使用 Copilot 免费版阻止匹配公共代码的建议吗？

Yes. 可以从 GitHub Copilot 设置 页配置这些设置。

Copilot Free 中包括哪些 Copilot 功能？

Copilot 免费版包括以下功能：Copilot 补全、编辑和聊天。 在关于 GitHub Copilot 免费版中了解更多信息。

Copilot 免费版对补全和聊天的限制是什么？

请参阅关于 GitHub Copilot 免费版获取信息。
