Devin 快速导览

Devin 是一名自主工作的 AI 软件工程师，能够编写、运行和测试代码。Devin 可以处理大多数任务 (极其困难的任务除外) 。一个经验法则是：如果你能在三小时内完成某件事情，Devin 大概率也能完成。可以让 Devin 处理 Linear/Jira 工单，实现全新的功能，复现并修复 bug，构建内部工具等！

在我们的发布说明中了解 Devin 的最新动态！

在某些情况下，Devin 的实际表现可能与本文所述并不完全一致，或者文档内容可能已过时。

​Devin 的优势是什么？

以下是 Devin 擅长处理的任务类型：

并行处理大量任务，在它们进入你的 待办列表 之前完成 Linear / Jira 工单 从零开始实现完整功能 Bug 报告 应用测试

代码迁移、重构和现代化改造 语言迁移 (例如：JavaScript 到 TypeScript) 框架升级 (例如：Angular 16 -> 18) 从 monorepo 转换为 submodule 移除未使用的 feature flag 将通用代码抽取为公共库

常见且重复的工程任务 PR Review 代码库问答 复现并修复 bug 编写单元测试 维护文档

客户工程支持 构建新集成并对接不熟悉的 API 创建自定义演示 方案原型设计 / 快速原型开发 构建内部工具

要从 Devin 获得最佳效果：

编写清晰的提示，并明确完成标准——任务越清晰，成功率越高，尤其是对复杂工作。

让任务易于验证——例如检查 CI 是否通过，或测试一次自动部署。

对于更难的任务，将其拆分为边界清晰的步骤，并提供相关上下文或示例。

遵循我们的最佳实践和任务前检查清单。

最有效的工作流程通常包括：

在你和同事在 Slack 或 Teams 讨论某个 bug 的会话线程中 @Devin

通过 Web 应用程序委派一个更复杂的任务，并在 Devin 的 IDE 给出不错的初稿后接手

在本地环境中运行 终端版 Devin，直接在命令行中进行快速修复、代码探索和交互式编码——然后使用 /handoff 将耗时更长的任务交给云端 Devin。

在一天开始时从待办清单中拆分出适合的任务交给 Devin，之后再回来查看等待你审核的草稿 PR

当你把 Devin 融入团队和现有工作流程时，它的效果最佳。

​产品通用功能

​Devin 界面

Devin 被设计为一个对话式用户界面，你可以在内嵌的 IDE 中实时查看并接管 Devin 的开发过程。Devin 也可以通过 Devin API 使用。

在 Devin 的 Workspace 中，你会看到 Devin 为你完成任务时使用的开发者工具。

Shell

Devin 的终端，你可以在这里观察命令的执行情况并查看输出日志。你也可以复制 Shell 输出用于调试。如果你想直接运行命令，请使用 IDE 的 Shell。

IDE

Devin 内嵌的代码编辑器，配备你熟悉的所有 IDE 工具和快捷键。你可以实时跟踪 Devin 的工作，并在需要时接管来运行命令、直接修改代码或测试 Devin 的代码。

Browser

你可以看到 Devin 如何浏览文档、测试其构建的 Web 应用程序、下载/上传信息等更多内容。你也可以通过 Interactive Browser 随时介入，帮助 Devin 完成浏览相关任务。

你可以在侧边栏或通过点击会话中的任意进度步骤来找到 Devin 的工具

​获取访问权限

要访问 Devin，请在 app.devin.ai 注册。提供个人和 Teams 套餐。

你也可以安装 Devin CLI，通过命令行直接使用 Devin：

curl -fsSL https://cli.devin.ai/install.sh | bash

如果你的公司已经在与 Cognition 合作，你可以向你的管理员或直接向 Cognition 申请权限，并通过 Web 应用 app.devin.ai 访问 Devin。

​反馈

我们一直在不断改进，而客户的意见至关重要！你可以发送邮件至 support@cognition.ai、通过 Slack Connect (适用于 Teams 用户) ，或直接在 Web 应用中点击 sidebar 底部的 Help (问号) 图标并选择 Contact support 来提交反馈。

我们会记录客户提供的所有反馈，用于快速改进 Devin，并指导我们的产品优先级和路线图规划。
