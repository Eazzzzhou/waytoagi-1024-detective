GitHub Copilot 计划

GitHub 提供适用于 Copilot 的多种方案。 根据你的需求，以及你是以个人身份使用 Copilot，还是作为组织或企业的一员使用 Copilot，选择其中之一。

** Copilot Free **： 开始使用 Copilot Free。

此计划包含对部分 Copilot 功能的有限使用权限，让你可以免费试用 AI 编码辅助功能。

** Copilot Student **：获取对 Copilot Student. 的访问权限。

仅向已验证身份的学生提供。 免费使用 Copilot 的各项功能。

** GitHub Copilot Pro **： 订阅 Copilot Pro。

专为希望更灵活地使用多种模型并享有每月 AI credits 额度的个人用户而设计。

** GitHub Copilot Pro+ **： 订阅 Copilot Pro+。

非常适合希望获得最先进功能的 AI 高级用户。 此付费计划包含 GitHub Copilot Pro 中的全部内容，并提供更高的每月额度 AI credits。

** GitHub Copilot Max **： 升级到 Copilot Max.

非常适合持续高频率使用 AI 的重度用户，此类用户希望获取最高可用的 AI 额度。 这个付费计划包括 Copilot Pro+ 中的所有内容，以及我们最高的个人每月额度 AI credits。

** GitHub Copilot Business **： 订阅 Copilot Business。

此计划面向组织和企业，为组织成员提供集中管理和 Copilot 策略控制。

** GitHub Copilot Enterprise **： 订阅 Copilot Enterprise。

专为使用 GitHub Enterprise Cloud 的企业打造。 此计划包含 Copilot Business 的全部功能，提供更大的每月 AI credits 额度，以及额外的企业级功能。

注意

Copilot 当前对 GitHub Enterprise Server 不可用。
