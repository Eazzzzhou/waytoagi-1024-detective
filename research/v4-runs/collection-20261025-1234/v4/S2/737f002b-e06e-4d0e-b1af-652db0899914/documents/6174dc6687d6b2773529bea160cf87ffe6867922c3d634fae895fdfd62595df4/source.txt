查看和更改GitHub Copilot 计划

了解如何查看、取消或更新计划 Copilot 。

复制 markdown

在本文中

可以在帐户设置中 GitHub 查看当前的计划详细信息。 本文中所述的计费和许可步骤仅适用于您可以登录到为该计划付费的个人帐户的情况。

如果有权通过组织或企业访问 GitHub Copilot，您的计划可以由组织或企业所有者修改。 请参阅 为你的团队管理 GitHub Copilot。

查看你的Copilot计划

在 GitHub 任意页面的右上角，单击你的个人资料照片，然后单击“ Settings”****。

在边栏的“Access”部分中，单击 “Billing & licensing”，然后单击“Licensing”（新平台）********。 或者，单击 计费和许可，然后单击 计划和使用情况（原始平台）。

在“许可”和“当前计划”下，可以看到当前使用的许可证和计划。

更改 Copilot 计划

可以随时从帐户设置升级或降级 Copilot 计划。

升级你的 Copilot 计划

在 GitHub 任意页面的右上角，单击你的个人资料照片，然后单击“ Settings”****。

在边栏的“Access”部分中，单击 “Billing & licensing”，然后单击“Licensing”（新平台）********。 或者，单击 计费和许可，然后单击 计划和使用情况（原始平台）。

在“GitHub Copilot”部分中，单击右侧升级的选项。

按照提示确认所做选择和计费详细信息。

降级你的 Copilot 计划

在 GitHub 任意页面的右上角，单击你的个人资料照片，然后单击“ Settings”****。

在边栏的“Access”部分中，单击 “Billing & licensing”，然后单击“Licensing”（新平台）********。 或者，单击 计费和许可，然后单击 计划和使用情况（原始平台）。

在“GitHub Copilot”部分中，选择右侧的 “管理订阅 ”下拉列表，然后单击可用的降级选项。

在降级模式中，你将看到以下选项： 保留现有计划，这将取消降级过程。 降级到低于当前计划的计划级别，新计划将在下一个计费周期开始时生效。 选择降级按钮进行确认。

取消 Copilot 计划

您可以随时取消您的 Copilot 计划。 在计费周期结束之前，你将继续享有当前功能的使用权限。 在您的计费周期结束时，将自动降级到 Copilot Free。

如果你是已验证的学生、教师或知名开源项目的维护者，并因此获得了对Copilot 的免费使用权限，则你将无法取消你的套餐。 如果您是通过组织或企业获得对 Copilot 的访问权限，则将无法取消您的套餐。 在这些情况下，可以在环境中禁用 Copilot 。 请参阅 在环境中配置 GitHub Copilot。

如果你当前有有效的Copilot Pro、Copilot Pro+或Copilot Max计划，随后又被分配到Copilot Business或Copilot Enterprise计划中的一个席位，你的个人Copilot计划将被自动取消。

在 GitHub 任意页面的右上角，单击你的个人资料照片，然后单击“ Settings”****。

在边栏的“Access”部分中，单击 “Billing & licensing”，然后单击“Licensing”（新平台）********。 或者，单击 计费和许可，然后单击 计划和使用情况（原始平台）。

在“GitHub Copilot”部分中，选择右侧的 “管理订阅 ”下拉列表，然后单击“ 取消订阅”。

选择 “取消”Copilot Pro/Copilot Pro+/Copilot Max 以在当前计费周期结束时取消计划。
