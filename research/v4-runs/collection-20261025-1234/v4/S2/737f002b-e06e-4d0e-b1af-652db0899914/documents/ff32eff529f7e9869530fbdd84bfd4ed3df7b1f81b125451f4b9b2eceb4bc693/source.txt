开始使用 GitHub Copilot 计划

您可以免费使用 Copilot，或选择付费计划以解锁更多功能、模型和请求额度。

您可以通过以下方式开始使用您的 Copilot 计划：

使用 Copilot 免费版

从 Copilot 免费版升级

订阅 Copilot Pro 或 Copilot Pro+

使用 Copilot 免费版

大多数个人开发者可以在无需任何设置的情况下开始使用 Copilot 免费版。但在以下几种情况下，Copilot 免费版不可用

您拥有受管理的用户账户。

您通过组织被分配了 Copilot 账户。

您已有 Copilot Pro 或 Copilot Pro+ 计划。

您通过 Copilot Student 获得了 Copilot 访问权限。

作为教师或开源维护者，您可免费使用 Copilot Pro。

根据您使用的环境，有几种方式可以开始使用 Copilot 免费版。

Visual Studio 和 VS Code

在 Visual Studio 和 VS Code 中，您可以直接从编辑器访问 Copilot 免费版。

在 Visual Studio 或 VS Code 右上角，点击 。

在侧边栏，点击 注册 Copilot 免费版。

如果您已有 GitHub 账户，系统会提示您登录；如果没有 GitHub 账户，系统会提示您创建一个。

GitHub.com

使用 Copilot 免费版，您可以在 GitHub 的聊天界面向 Copilot 提问。前往 https://github.com/copilot 开始与 Copilot 对话。

GitHub Mobile

您也可以在 GitHub Mobile 中与 Copilot 进行聊天。

在 GitHub Mobile 中，点击屏幕右下角的 图标。 注意 GitHub Mobile 并非在所有页面都显示 图标。若未看到该图标，请在 GitHub Mobile 中切换到其他页面并查找该图标。

在页面底部，使用 “Ask Copilot” 框开始与 Copilot 对话。

其他 IDE

要在其他 IDE 中使用 Copilot 免费版，您需要先在 GitHub 账户设置中激活它。

在 GitHub 任意页面的右上角，点击您的头像，然后点击 Copilot 设置。

点击 开始使用 Copilot 免费版 以激活 Copilot 免费版并打开 https://github.com/copilot。

在右上角，Download 旁边，选择下拉菜单并点击您首选的编辑器。

从 Copilot 免费版升级

如果您已经在使用 Copilot 免费版且达到使用上限，系统会直接提示您升级。升级体验因您使用 Copilot 的环境而异。

在 Visual Studio、VS Code 或 GitHub.com：您会收到一条包含重置日期以及升级至 Copilot Pro 或 Copilot Pro+ 链接的消息。

在其他 IDE 中：会显示错误信息。您可以在 GitHub Copilot 设置 中开始付费计划。

在 GitHub Mobile 中：当您达到使用上限时，系统会提示您通过应用内购买升级。

订阅 Copilot Pro 或 Copilot Pro+

您可以随时订阅 Copilot Pro 或 Copilot Pro+，以解锁高级 AI 功能、更高的使用额度以及更多模型。

提示

不确定选择哪个计划？欲查看并排比较，请参见 关于个人 GitHub Copilot 计划及福利。

前往 计划页面。

在您想订阅的计划下点击 开始使用。

点击 订阅 Copilot Pro/Copilot Pro+。 如果您的个人账户符合免费 GitHub Copilot 计划的条件而非付费计划，系统会自动跳转到第 6 步。

若要开启超出包含的高级请求配额的使用，请选择 是，我想启用 Copilot 高级请求的额外使用量。您可以随时更改此设置。点击 保存并继续。

按照步骤输入并确认您的账单信息和支付详情，然后点击 提交。

在查看完计划详情后，点击 激活 Copilot Pro/Copilot Pro+。
