获取 GitHub Copilot 访问权限

Copilot 免费版每月提供最多 2,000 次代码补全和 50 条聊天消息，完全免费。 开始使用 Copilot 免费版。

如需更高配额和所有可用模型的访问权限，请订阅 Copilot Pro 或 Copilot Pro+。请参阅 GitHub Copilot 计划入门指南，了解所有计划的详情，包括面向学生、教师和开源维护者的免费选项。

配置设置（可选）

如果您拥有自己的 Copilot 计划，可在 Copilot 设置 中管理您的策略和功能访问权限。您还可以启用 Copilot 记忆，让 Copilot 记住有关您仓库的有用上下文。

设置个人自定义指令（可选）

个人自定义指令告诉 Copilot Chat 您的偏好——例如您偏好的语言、编码风格或响应格式。要添加这些指令，请在 GitHub 上打开任意 Copilot Chat 对话，点击您的头像，然后选择 个人指令。更多信息，请参阅 为 GitHub Copilot 添加个人自定义指令。

下一步

在 GitHub 上与 Copilot 聊天，获取有关您的代码、仓库和开发问题的答案。
