BlenderMCP 是一种基于 MCP（Model Context Protocol，模型上下文协议）的插件系统，可将 Blender 与 Claude AI 无缝连接。通过该集成，Claude 可以读取 Blender 场景信息，甚至直接控制建模、材质、相机等操作，让 AI 参与到你的 3D 建模工作流中，大幅提升效率。

本文将一步步教你如何安装所需组件、配置环境，并在 Claude 中通过自然语言指令控制 Blender。

一、所需软件与安装顺序

以下是使用 BlenderMCP 所需的组件，请按照顺序安装：

1. Blender（3.0 或更高版本）

前往 Blender 官网 下载并安装最新版本。推荐使用稳定版本 3.0 以上。

2. Python（3.10 或更高版本）

Blender 自带内置 Python，但 MCP 服务依赖系统中的 Python 环境。你可以从 Python 官网 安装 Python 3.10+，并确保 python 命令可在终端中使用。

3. 安装 uv 包管理器
